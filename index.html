Algorithm Explanation

Dijkstra's algorithm finds the shortest path from a starting point to all other points in a weighted graph. Here, each building is a node, each footpath is an edge, and the edge weight is the distance in metres.

  1. Set the distance of the starting building to 0 and all other buildings to ∞.
  2. Choose the unvisited building with the smallest distance.
  3. Check all its nearby buildings. If current distance + path length is smaller than the old distance, update the distance.
  4. Mark the selected building as visited. Its distance is now final.
  5. When the destination is reached, stop. Follow the saved path backwards to get the complete shortest route.
