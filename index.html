Algorithm Explanation

Dijkstra's algorithm finds the shortest path from a starting point to other points in a weighted graph. Each building is a node, each footpath is an edge, and the edge weight is the distance in metres.

  1. Set the starting building's distance to 0 and all other buildings' distances to infinity.
  2. Choose the unvisited building with the smallest distance.
  3. Check its neighbouring buildings. If the new distance is smaller, update the distance.
  4. Mark the selected building as visited.
  5. Continue until the destination is reached, then reconstruct and display the shortest route.
